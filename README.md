# 你好，我是杜玉鹤 👋

## 🌱 关于我

我的兴趣爱好是跑步和写小说。跑步让我在学习之余放松下来，写小说则让我有机会观察生活、构思人物，把脑海中的想法慢慢写成故事。

对我来说，值得分享的经历是坚持尝试写作。从一个想法到一段完整的情节，需要不断补充细节、调整表达。这也让我认识到，很多事情都需要先动手，再在修改中逐步完善。

最近，我正在整理自己的学习内容，学习使用 GitHub 和 Markdown，希望把零散的练习与笔记积累成能够回顾、展示和交流的成果。

我目前对软件开发和人工智能应用比较感兴趣。软件开发能够把想法变成可以使用的工具，而人工智能应用让我想进一步了解模型背后的原理，以及它在具体任务中的能力和局限。

## 🗓️ 未来三年规划

我目前是一名大三学生，接下来的主要目标是考研。我希望通过研究生阶段的学习，进一步夯实计算机专业基础，接触更深入的研究问题，也为未来从事技术相关工作积累能力。

### 第一年：大三，明确目标并系统备考

大三阶段，我会在完成专业课程的同时，把考研准备纳入日常安排。结合自己的专业兴趣、学习基础和目标院校公布的招生信息，逐步确定报考院校与专业，明确需要准备的考试科目。

学习上，持续积累英语词汇和阅读能力，系统复习报考方向要求的数学与专业课内容。通过阶段练习检查薄弱环节，定期调整复习安排，并利用大三暑假开展强化训练。

同时，整理已有课程实验和学习笔记，适量保留编程练习，巩固实际动手能力。

### 第二年：大四，完成考研与本科毕业任务

大四上学期，我会把学习重点放在考研复习和初试准备上，通过真题练习、模拟训练和错题复盘，提高知识掌握程度与答题效率，并及时关注报考信息，完成相关手续。

初试结束后，结合考试情况准备后续环节，重点复习专业基础，练习英语表达，整理个人介绍和项目经历，为复试做好准备。

大四下学期，还要合理安排毕业设计、毕业论文和剩余课程，把考研后续准备与毕业任务统筹起来，按要求完成本科阶段的学习。

### 第三年：毕业后第一年，适应研究生学习

如果顺利录取，我希望在研一阶段完成从本科课程学习到研究训练的过渡。认真学习研究生课程，在与导师交流、阅读文献和参与课题的过程中，逐步明确研究方向。

能力提升上，重点练习英文文献阅读、实验复现、结果分析和学术写作。从规模适当的任务做起，学会清楚地提出问题、记录过程，并用证据检验自己的想法。

如果升学结果未达到预期，我也会结合成绩、个人意愿和实际条件，认真评估再次报考或就业的选择，及时调整安排。

这三年里，我也希望继续保持跑步和写作的习惯，让学习、兴趣和生活形成能够长期坚持的节奏。
